📁 Carpeta para tus archivos de música

Coloca aquí tus archivos MP3, WAV o FLAC para analizarlos.

Formatos soportados:
- .mp3
- .MP3
- .wav
- .flac

Ejemplo:
  mis_canciones/
     ├── cancion1.mp3
     ├── cancion2.mp3
     ├── cancion3.mp3
     └── ...

Luego ejecuta:
  python main.py

¡Y listo! El sistema analizará todas tus canciones automáticamente.
